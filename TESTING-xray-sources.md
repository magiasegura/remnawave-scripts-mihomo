## Среда и воспроизведение

На SKY-K10 использован установленный MSYS2 Bash. Для остальных утилит доступен
Git for Windows. MSYS2 Bash и `flock` должны использовать одну среду исполнения:
запуск `flock` из MSYS2 непосредственно под Git Bash приводит к ошибке файлового
дескриптора. Временный каталог задан общим абсолютным путём `/c/...`, потому что
папки `/tmp` у этих установок различаются.

Эквивалент команды внутри MSYS2, с доступными утилитами и Node.js в PATH:

```bash
export PATH="/usr/bin:/c/Program Files/Git/usr/bin:$PATH"
export TMPDIR=/c/path/to/shared-existing-temp-directory
cd /c/Users/SKY/Desktop/vibecoding/remnawave-scripts-mihomo
bash -n remnanode.sh
bash -n remnanode-xray-update.sh
bash tests/run-tests.sh
```

На Linux достаточно команд из README. Новые сценарии извлекают функции
непосредственно из исходников и используют изолированные временные каталоги.
Операции с файлами, блокировкой и резервными копиями настоящие. Сеть, Docker
и скачанный бинарник подменены тестовыми функциями или shell-фикстурами.

GitHub API дополнительно проверен без изменения удалённых ресурсов:
у Jolymmiles релиз `v26.11.10-1249` содержит `Xray-linux-64.zip` и
`Xray-linux-arm64-v8a.zip`. Это проверка формата публикации, а не запуск сборок.

## Что не проверялось

Рабочие серверы не подключались и не изменялись. Linux-контейнеры и реальные
ELF-сборки Xray не запускались. Docker Desktop на этом компьютере не запущен,
WSL не содержит установленного дистрибутива. ShellCheck не установлен.
Клиентские соединения, панель Remnawave и совместимость конкретной конфигурации
с форком требуют отдельного прогона на тестовой Linux-ноде.
